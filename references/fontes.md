# Fontes da disciplina

Nenhuma fonte deste projeto foi incorporada até aqui. Os PDFs anexados ao projeto ainda não estavam acessíveis no ambiente de criação da skill. Não atribua regras específicas à disciplina sem consultar os materiais correspondentes.

Ao receber os PDFs, registre neste índice para cada arquivo: identificador, título, versão ou data informada, hash SHA-256, páginas pertinentes, área de aplicação e referência que contém as regras extraídas. Consulte [o procedimento de atualização](atualizacao.md) para revisar este índice e as instruções da skill.
